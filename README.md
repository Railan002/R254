# R254# Football Prediction App (Low-Risk Bets)

This is a Streamlit web app that fetches and displays **low-risk football matches** with odds under 1.60 using The Odds API. It helps identify safer games to consider for betting.

## Features

- Filters today's football matches
- Shows odds ≤ 1.60 (lower-risk matches)
- Displays teams, odds, bookmakers, and win probability
- Simple and clean interface via Streamlit
